# Sils — سلس

Official Windows releases of Sils video studio. This repository contains application installers and signed update manifests only. The application source code is not published here.

## Download

Get the installer from [Releases](https://github.com/Amoag/sils-releases/releases/latest). A valid activation serial is required to use the application.

## Updates

Newer builds notify you when an update is available. Open Settings, download the update, then choose Install update and restart after finishing processing. Updates preserve application settings, activation and optional engine packs.
