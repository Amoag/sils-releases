# Sils — سلس

**استوديو فيديو لنظام Windows، بواجهة عربية وإنجليزية، لتعديل المقاطع وتحسينها وتجهيزها للرفع على تيك توك.**

يجمع سلس أدوات القص، وتعديل الأبعاد، والفلاتر، واستيفاء الفريمات، وتحسين الدقة في واجهة واحدة. تتم معالجة الفيديو محليًا على جهازك، ويُصدّر الناتج بصيغة **MP4 بترميز H.264** وصوت **AAC** عند وجوده.

## المميزات

### 🎬 القص والأبعاد

- تحديد بداية المقطع ونهايته، مع قص الفيديو والصوت معًا.
- تغيير نسبة الأبعاد إلى **9:16، 16:9 أو 1:1**.
- تدوير الفيديو، أو احتواء الصورة كاملة، أو قصها لملء الإطار.
- تحريك إطار القص مباشرةً داخل المعاينة.

### 🎨 الفلاتر والألوان

- مكتبة فلاتر منظمة حسب المجموعات، مع المفضلة والمستخدمة مؤخرًا.
- عرض عينات ألوان كل فلتر داخل بطاقته.
- استيراد فلاتر شخصية بصيغة **LUT ‎`.cube`**.
- التحكم في قوة الفلتر ومزج الألوان والتباين.
- خيارات للحدة وتمويه الحركة.

### ↔️ مقارنة قبل وبعد

- مقارنة ألوان الفلتر بسلايدر داخل المشغل.
- اختيار موضع المعاينة ومدتها.
- جودة تلقائية تراعي إمكانات الجهاز، أو اختيار جودة تصل إلى **4K** بحسب المصدر.
- إنشاء المعاينة عند الطلب، مع إمكانية إلغائها.

> معاينة المقارنة مخصصة لألوان الفلاتر؛ لا تشمل الاستيفاء أو تحسين الدقة أو الحدة أو تمويه الحركة.

### ⚡ الحركة وتحسين الدقة

- استيفاء الحركة باستخدام **RIFE** للوصول إلى 60 فريم.
- خيار **120 فريم تجريبي**.
- محرك تحسين سريع يعتمد على **Vulkan**.
- محرك متوازن يعتمد على **TensorRT** لبطاقات NVIDIA المتوافقة.
- حزم تحسين اختيارية تُحمّل من داخل التطبيق.

### 📦 التصدير وإدارة الملفات

- تجهيز الناتج بطريقة **Ghost**.
- حفظ ملف نهائي بجانب المصدر افتراضيًا، مع إمكانية اختيار مجلد آخر.
- تغيير اسم الناتج وفتح مجلده مباشرةً.
- سجل للعمليات والنتائج، مع خيارات حذف السجل أو الملفات المعالجة.
- تنظيف الكاش مع الحفاظ على الإعدادات والتجهيزات المحفوظة.

### ✨ تجربة الاستخدام

- واجهة عربية وإنجليزية مع اتجاه عرض مناسب لكل لغة.
- تصاميم متعددة وتحكم في حجم الواجهة.
- حفظ التجهيزات، والتراجع والإعادة، واستعادة إعدادات كل قسم بشكل مستقل.
- تعليمات مختصرة عند تمرير المؤشر وقسم مساعدة.
- تفعيل بمفتاح ترخيص، والتحقق من تحديثات التطبيق وتحميلها وتثبيتها.

## بدء الاستخدام

1. حمّل أحدث إصدار من صفحة **Releases** وثبّت التطبيق.
2. أدخل مفتاح التفعيل.
3. اختر المقطع واضبط الإعدادات المطلوبة.
4. راجع ألوان الفلاتر بالمعاينة، ثم جهّز المقطع.
5. افتح مجلد الناتج وارفعه عبر [تيك توك استوديو](https://www.tiktok.com/tiktokstudio/upload).
